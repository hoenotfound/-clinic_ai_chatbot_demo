# Sales journey demo upgrades

This branch adds three public-demo improvements without connecting to production messaging or customer data.

## Automated follow-up demo

The Tools page now includes an interactive simulation showing a warm lead going quiet, the inactivity timer, eligibility checks, and the eventual follow-up message. The simulation never sends a real outbound message.

## Live lead transformation

The live Demo Patient card in Pipeline is visually highlighted and auto-updates as the Patient View conversation changes. Prospects can watch the lead move from New Enquiry to Qualified and then Appointment Requested while treatment, branch and lead temperature update.

## Appointment pipeline

Pipeline stages are now:

1. New Enquiry
2. Qualified
3. Appointment Requested
4. Appointment Confirmed
5. Visited
6. Won

Sample confirmed appointments are included so the appointment journey is visible immediately.
